# Application Flow Component

This component is designed to display the Endao Application Flow from Figma.

## Figma Design Link
https://www.figma.com/design/BTUpRGvjPQgj9ZuTVLHZTG/Endao-Application-Flow?node-id=21578-118476

## How to Generate Code from Figma

### Using PhpStorm AI Assistant with Figma MCP

1. **Open PhpStorm AI Assistant**
2. **Use this prompt**:

```
Generate Angular component code from this Figma design:
https://www.figma.com/design/BTUpRGvjPQgj9ZuTVLHZTG/Endao-Application-Flow?node-id=21578-118476&t=7OGS3JhFYk4gxRGL-0

Please create:
- HTML template with proper structure in application-flow.html
- CSS styles matching the Figma design in application-flow.css
- TypeScript component logic if needed in application-flow.ts

The component should be responsive and match the Figma design as closely as possible.
```

3. **The AI will**:
   - Extract the design from Figma
   - Generate HTML structure
   - Create matching CSS styles
   - Provide any necessary TypeScript logic

4. **Update the files** with the generated code

## Component Files

- `application-flow.ts` - Component TypeScript class
- `application-flow.html` - Component template
- `application-flow.css` - Component styles

## Routing

The component is already configured with routing:
- Route: `/application-flow`
- Default route redirects to this component
